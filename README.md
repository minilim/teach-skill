# teach — скилл для Claude

Копия скилла `teach` из репозитория [mattpocock/skills](https://github.com/mattpocock/skills) (папка `skills/productivity/teach`), выложенная отдельно для удобной установки в проект Claude по [мини-гайду «Как настроить Claude для помощи ребёнку с учёбой»](#).

Скилл превращает Claude в репетитора: он запоминает прогресс ребёнка, ведёт занятия небольшими шагами и подбирает посильную сложность вместо того, чтобы просто выдавать готовые ответы.

## Как использовать

1. Скачайте файлы этого репозитория (Code → Download ZIP).
2. Следуйте шагу 5 мини-гайда, чтобы добавить скилл в проект Claude.
